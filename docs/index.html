NGR001 Geocluster - Module Documentation

This documentation provides detailed information about the module interfaces for the NGR001 Real-Time Geospatial Event Clustering System. The system enables visualization and analysis of geospatial events through H3 hexagonal binning and DBSCAN clustering algorithms.

Backend API (Python/FastAPI)

The backend provides REST API endpoints for event management and spatial clustering.

  • app - Main application package
  • app.main - FastAPI application and REST endpoints
  • app.models - SQLAlchemy ORM models for events
  • app.schemas - Pydantic schemas for request/response validation
  • app.crud - Database CRUD operations with PostGIS
  • app.clustering - H3 binning and DBSCAN clustering algorithms
  • app.db - Database connection and session management

Frontend (TypeScript/React)

The frontend provides an interactive map visualization using MapLibre GL and deck.gl.

  • Frontend Modules - TypeDoc generated documentation
  • api.fetchH3 - Fetch H3 hexagonal aggregations
  • api.fetchEventsInHex - Fetch events within a hexagon
  • api.updateEventsBulk - Bulk update events

API Endpoints

The backend exposes the following REST API endpoints:

  • GET /health - Health check
  • POST /events/bulk - Bulk insert events
  • PATCH /events/bulk_update - Bulk update events
  • GET /events - Query events with spatial/temporal filters
  • GET /aggregations/h3 - H3 hexagonal aggregation
  • GET /clusters/dbscan - DBSCAN clustering
